# Real-Time Character Counter 📝

A simple, responsive web application that provides users with a multi-line text area and tracks their input length in real time. It enforces a strict character limit and alerts users when the maximum allowance is reached.

## 🚀 Features

* **Multi-line Text Area:** Accessible layout optimized for longer message composition.
* **Real-Time Counter:** Dynamic tracking that instantly updates the current character count and remaining capacity (e.g., `150 / 200 characters`).
* **Strict Input Hard-Stop:** Automatically truncates extra text if a user tries to type or paste past the designated limit.
* **Visual Warnings:** Triggers a visible warning message the moment the user hits the maximum limit.

## 📋 Requirements Satisfied

* [x] Create an HTML text area displaying maximum allowed characters.
* [x] Add an event listener tracking the `input` event to update the counter in real time.
* [x] Display a structural counter tracking typed vs. remaining characters.
* [x] Block further typing and display a clear warning message upon exceeding constraints.

## 🛠️ Built With

* **HTML5** - Document structural layout
* **CSS3** - Custom typography and clean interface elements
* **Vanilla JavaScript** - Dynamic DOM manipulation and real-time event handling
